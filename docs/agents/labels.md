# Подписи, язык карты и значки POI

Справочная часть `AGENTS.md`. Проверки — `tests/test_template_styles.py`
(стиль) и `tests/test_label_abbreviations.py` (сокращения).

## Линия подписи вдоль полигона

- **Линия подписи вдоль полигона** (`core/label_line.py`) строится своим
  алгоритмом вместо скелета GRASS. У ледников путь для сравнения ширин уже
  посчитан — `_axis_attempt` переиспользует его вместо повторного
  `centered_path`, если концы не поменялись местами; при смене начала путь
  пересчитывается, иначе разворот даёт другой выбор при равной стоимости.
  Проверка — совпадение линий на всех ледниках проекта.
- **Готовые линии подписи кэшируются** (`core/label_cache.py`): линия —
  чистая функция геометрии слоя, а расчёт занимает больше десяти секунд на
  ледниках и лесах. Ключ кэша — версия алгоритма, имя слоя, режим линии
  (`main_flow`) и отпечаток содержимого исходного слоя
  (`terrain_cache.layer_digest`), поэтому изменившийся слой пересчитывается.
  Кэш лежит в `<проекты>/qgisxtopo-cache/labels`, в нём остаётся несколько
  последних записей. При изменении алгоритма поднимайте `LABEL_CACHE_VERSION`,
  иначе старые линии вернутся из кэша. Проверка — `LabelCacheTest` в
  `tests/test_pipeline_logic.py`.
- **Проверка линии подписи работает без рабочих данных.** Отмеченные
  объекты лежат в каталогах пользователя, поэтому в репозитории лежат
  упрощённые копии всех 68 (`tests/data/label_cases.json`): для каждого
  проверяются нормы пользователя и сама линия (отклонение больше метра —
  ошибка). Файл собирается `tools/make_label_fixtures.py`; после изменения
  алгоритма линии его нужно пересобрать, иначе эталон останется прежним.
  Нормы приходится поправлять, когда огрубление меняет форму: норма
  смещения тогда поправляется на достижимую, а исходная остаётся в
  `source_rules`. Полные 68 отмеченных случаев на настоящих данных
  проверяются, когда заданы `QGIS_XTOPO_TEST_VECTOR` и
  `QGIS_XTOPO_TEST_GLACIER`.

## Углы поворота значков

- **Угол значка перевала и станции считается при подготовке**
  (`core/icon_angles.py`), а не выражением в шаблоне: QGIS при каждой
  отрисовке строил индекс всего слоя гребней или рельсов. В слои значков
  пишутся поля `icon_angle` (угол в градусах) и `icon_building` (станция
  рядом со зданием вокзала), в шаблоне остаётся только обращение к полю.
  Значения совпадают с прежними: углы считает тот же движок выражений QGIS,
  теми же выражениями из шаблона, один раз за подготовку. Проверка —
  `IconAngleTest` в `tests/test_template_styles.py` и `tests/test_pipeline_logic.py`.
- **Условие по переменной проекта остаётся в шаблоне**
  (`IF(@rotate_mountain_pass IS 'true', "icon_angle", '')`): переключатель
  поворота должен работать и после подготовки.
- **Слои-источники подключаются отдельным хранилищем** (`QgsMapLayerStore`):
  в проекте лежат шаблонные слои с теми же именами, они указывают на ещё
  не готовые файлы, и выражение нашло бы их вместо подготовленных.

## Язык карты

- Язык карты задаётся переменными проекта. **Пустое значение переменной
  удаляется**, `@name_pref_suf_lang` становится NULL, QGIS не вызывает функцию
  подписи, и названия исчезают. Защита внутри выражений не помогает: QGIS до
  них не доходит.
- `@name_pref_suf_lang` равен `ru` даже при «Местных названиях»: тип объекта
  сокращается по-русски всегда («ледник» → «л.», «брод» → «бр.»).
- `level_of_detail` — переменная, на которой держатся фильтры отрисовки во
  многих слоях (дороги, тропы, родники). Без неё правила ложны. Панель: 3–6,
  по умолчанию 4, ключ `SETTINGS_KEY_DETAIL`; в новый проект попадает через
  `project.py: _set_detail_variable`.
- `pick_name_part` (`core/transliteration.py` +
  `resources/expressions/transliterate.py`): берёт кириллическую часть,
  помеченную языком (`ru: ...`) или скобками с той же строкой другой азбукой;
  скобки-уточнения (`Mersedes Benc (грузовой)`) название не заменяют. Дефис
  внутри слова не делит, тире с пробелами делит. При `script="local"` название
  выводится целиком.
- Русский тип объекта (`л.`, `м.`, `хр.`, `ур.`) приписывается только
  кириллическому названию (`_has_cyrillic` в `resources/expressions/
  format_*.py`). Название из одного слова типа не дополняется префиксом.
  Списки типовых слов у водной и населённой групп должны совпадать.
- **«(неж.)» у населённых пунктов** скрывается по тем же условиям, что
  категория сложности перевала: пометка не приписывается имени не кириллицей
  на нерусской карте, включая «Местные названия»; на русской карте и для
  кириллических имён она остаётся. Проверка — тесты `uninhabited_place` в
  `tests/test_label_abbreviations.py`.
- Выражения (`readable_name`, `format_place_name`, `pick_name_part`, ...)
  регистрируются `core/expressions.py: load_expressions()`. Если функции нет,
  QGIS не рисует подписи. Доступные функции — `registered_functions()` через
  `QgsExpression.Functions()`; `registeredFunctionNames()` в QGIS нет.

## Вытеснение значков POI

- **Действует и внутри слоя.** Фильтр подавления скрывает значок, если рядом
  есть точка с меньшим рангом **или с тем же рангом, но меньшими
  координатами**. Без второго условия значки одного слоя (населённые пункты,
  хижины) на мелких масштабах накладывались бы друг на друга; победитель
  кластера остаётся в служебном слое (`_prune_band` в `core/poi_icons.py`).
  **`geometry(@parent)` в `overlay_nearest` не работает** — `@parent` доступен
  только в `aggregate`, внутри аргументов overlay он NULL (проверено на QGIS
  3.44). Поэтому родительская точка передаётся через
  `with_variable('pg', $geometry, ...)`, а `overlay_nearest` возвращает массивы
  `array(x($geometry), y($geometry), rank)`. Приоритет и точное расстояние в
  метрах считаются снаружи вызова через `array_filter` с `@element`;
  `max_distance` — только градусный конверт для индекса. Размер значка —
  видимая часть SVG (`_svg_content_scale`: рендер в QImage и bbox по альфе), а
  не весь холст: у пика рисунок занимает ~72 %, у станции подъёмника ~78 %, и
  прозрачные углы не должны скрывать соседей. Фильтры запечены в шаблон; при
  перегенерации кавычки в XML экранировать (`&quot;`), иначе файл ломается.
  Проверки — `PoiSuppressionExpressionTest`,
  `test_icon_rules_break_ties_within_a_layer`, `PoiPruneTest`.
- **Значки на линиях и полигонах — препятствия для POI.** У мостов значок
  рисуется `MarkerLine` с `CentralPoint`, у кладбищ — `CentroidFill`; фильтр
  правила скрыл бы весь мост или площадку. В служебный слой добавляется одна
  точка на объект (середина линии или `pointOnSurface`) с рангом меньше 1 —
  выше любого POI (`read_template_obstacles`, `_icon_anchor`). Ленты стрелок и
  ЛЭП не обрабатываются: у них значков вдоль линии много, одна точка в
  середине соврала бы. `_prune_band` сравнивает расстояние с размером значка
  **того объекта, который будет скрыт**, а не с глобальным максимумом, иначе
  в служебный слой попадала половина мостов. Проверка — `PoiObstacleTest`.
- **Значки мостов одного слоя вытесняют друг друга.** Линия и значок моста
  рисуются разными правилами: исходное правило оставляет только `SimpleLine`,
  а значок вынесен в отдельное правило на каждый канонический диапазон
  масштаба. QGIS рисует все совпавшие правила, поэтому `_RuleEvaluator._descend`
  возвращает максимальный размер значка среди подходящих листьев: иначе
  правило линии (size 0) скрывало бы значок. При подготовке данных
  `_write_icon_hide` пишет в слои мостов поле `icon_hide` — индексы диапазонов,
  где рядом есть мост того же слоя с меньшими координатами
  (`_hidden_bridge_bands`). У `MarkerLine` маркерного правила задано
  data-defined `enabled` (`poi_icons.icon_enabled_expression`): false, если
  диапазон есть в `icon_hide`, иначе true. Свойство `enabled` отключает только
  значок, линии остаются. **`overlay_nearest` в data-defined свойствах символа
  вешает отрисовку — не использовать.** Побеждает объект с меньшими
  координатами, как у точечных POI; `_prune_band` не берёт скрытые значки в
  служебный слой. У `highway main bridge` service-мосты на 200k+ остаются
  линиями, но без значка (у символа 200000–300000 удалён `MarkerLine`,
  маркерных правил для него нет), поэтому на 1:200000 и мельче их значки не
  появляются. Проверки — `BridgeIconSuppressionTest`, `BridgeIconHideTest`.
- **Все слои со значками — только EPSG:4326, имена служебных слоёв не
  повторяются.** Точное расстояние подавления считается в метрах по
  координатам кандидатов, поэтому все слои должны быть в градусах; слой в
  EPSG:3857 дал бы неверные метры. Поэтому рецепты `mountain_pass`,
  `railway_station_icons`, `railway_halt_icons`, `aerialway_station` не должны
  заканчиваться `reproject()` (проверка — `PoiRecipeCrsTest` в
  `tests/test_pipeline_logic.py`). Служебных файлов один — `poi_icons.gpkg`;
  прежний `poi_icons_3857.gpkg` удаляется при сборке. Два слоя с одинаковым
  именем «poi icons N» (было: 4326 и 3857) делали выбор `overlay_nearest`
  неоднозначной — первым находился слой не той системы координат, и вытеснение
  не работало вовсе. Проверки —
  `test_service_layer_names_are_unique_and_referenced` и
  `test_all_icon_layers_use_one_crs`.
