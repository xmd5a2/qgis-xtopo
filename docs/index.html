QGIS-xtopo

Топографическая стиль и подготовка данных OSM и рельефа для QGIS.

Плагин готовит данные OpenStreetMap и рельефа (SRTM) и собирает проект QGIS из шаблона automap.qgz: скачивает нужные карты, вырезает из них область, раскладывает объекты по слоям, строит DEM и изолинии и удаляет пустые слои.

  • Подготовка данных из Geofabrik, Overpass API или локальных PBF.
  • Рельеф: DEM, отмывка, изолинии, ледниковые и обычные горизонтали.
  • Язык карты: выбор языка названий, транслитерация, сокращения типов.
  • Инсталлятор для Windows и запуск QGIS с открытой панелью.

Подробное описание — в README репозитория.
